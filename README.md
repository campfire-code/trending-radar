# 全网热点雷达

> 篝火出品 · 收录于篝火 App 应用区

聚合各平台热榜，按关键词提醒

![界面截图](docs/screenshot.png)

## 下载

到 [Releases](https://github.com/campfire-code/trending-radar/releases/latest) 下载对应安装包：

| 电脑 | 文件 |
|---|---|
| Windows 10 / 11 | `trending-radar_版本号_windows-x64-setup.exe` |
| Mac（Apple 芯片） | `trending-radar_版本号_mac-arm64.dmg` |
| Mac（Intel 芯片） | `trending-radar_版本号_mac-x64.dmg` |

第一次打开：
- **Windows**：如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
- **Mac**：如果提示「无法验证开发者」，打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」。

## 怎么用

一次看 14 个中文热榜，按关键词盯住你关心的话题：

| 分类 | 来源 |
|---|---|
| 综合 | 微博热搜、知乎热榜、百度热搜、抖音热榜、B 站热搜、今日头条、澎湃热榜、贴吧热议 |
| 科技 | 36 氪快讯、IT 之家、少数派、稀土掘金 |
| 财经 | 华尔街见闻（快讯）、财联社电报 |

1. 打开就会自动抓取一次，每个来源一张卡片，显示排名、标题、热度，点标题在浏览器里打开原文。
2. 在顶部输入**订阅关键词**（空格、逗号、顿号都能分隔，例如 `AI 新能源 地震`），按回车生效。命中的标题会高亮，并在最上方「命中关键词」里汇总；刷新后新出现的命中会标「新」。
3. 勾选「只看命中」，每张卡片只留下命中的条目。
4. 「自动刷新」可选每 5 / 10 / 15 / 30 / 60 分钟，**最短 5 分钟**，避免频繁请求被网站限制。也可以随时点「刷新」。
5. 点来源标签可以隐藏 / 显示该来源（至少保留一个）。某个来源抓取失败时卡片里显示原因和「重试」，不影响其他来源；标签上会出现红点。
6. 「导出 Excel」「导出 Markdown」把当前显示的来源导出到「下载/全网热点雷达」文件夹，文件名形如 `热点-20261023-1730.xlsx`。勾了「只看命中」就只导出命中的条目。

**其他说明**
- 不需要登录任何账号，也不需要大模型。关键词、刷新间隔、来源开关保存在本机。
- 热榜数据直接从各网站公开页面 / 接口获取，网站改版时个别来源可能失效（卡片会提示「网站结构可能变了」），等待新版本修复即可。
- 微博热搜使用公开的访客 cookie，抖音先访问其登录页取得访客 cookie，都不涉及个人账号。

## 验收用例

| 操作 | 应得到 |
|---|---|
| 打开工具（联网） | 14 张来源卡片陆续出现内容，状态行显示「更新于 时:分 · 14 个来源，成功 N 个」；每张卡片至少 5 条，带排名 |
| 关键词框输入 `samples/订阅关键词示例.txt` 里的 `地震 AI 央行`，回车 | 含这些词的标题出现高亮；最上方出现「命中关键词」列表，状态行显示「命中 N 条」，N 与列表条数一致 |
| 勾选「只看命中」 | 各卡片只剩命中条目，没有命中的卡片显示「这里没有命中关键词的条目」 |
| 断开网络后点「刷新」 | 每张卡片显示「连不上该网站，检查网络或代理设置」和「重试」按钮，界面不崩溃；恢复网络后点某张卡片的「重试」，只有这一张恢复 |
| 自动刷新选「每 5 分钟」，等 5 分钟 | 状态行时间自动更新；下拉框里没有小于 5 分钟的选项 |
| 点「导出 Markdown」 | 「下载/全网热点雷达」里生成 `热点-日期-时分.md`，格式与 `samples/示例导出-全部.md` 一致：每个来源一个二级标题，条目带链接和热度，命中的条目加粗并标出关键词，失败的来源写「抓取失败：原因」 |
| 勾「只看命中」后点「导出 Excel」 | 生成 `热点-日期-时分.xlsx`，表头为「来源、排名、标题、热度、链接、命中关键词、抓取时间」，只含命中行，链接可点击；结构与 `samples/示例导出-只看命中.xlsx` 一致 |
| 点任意标题 | 系统默认浏览器打开该条热点的原文页面 |

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
